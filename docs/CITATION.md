# Cite ActionPlan Kit

Use the repository's **Cite this repository** button for APA or BibTeX, generated from
[CITATION.cff](../CITATION.cff). Cite the release you actually used.

Example for this release:

> Nikhare, A. (2026). ActionPlan Kit (Version 0.2.1) [Computer software].
> https://github.com/akshaynikhare/action-plan-kit/releases/tag/v0.2.1

```bibtex
@software{nikhare_actionplan_2026,
  author  = {Nikhare, Akshay},
  title   = {ActionPlan Kit},
  year    = {2026},
  version = {0.2.1},
  url     = {https://github.com/akshaynikhare/action-plan-kit/releases/tag/v0.2.1}
}
```

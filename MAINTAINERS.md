# Maintainers and project decisions

**Akshay Nikhare — [@akshaynikhare](https://github.com/akshaynikhare)** is the current maintainer
and release owner. CODEOWNERS requests review from this account.

Contributors propose changes through issues and pull requests. The maintainer decides whether a
change fits the project, reviews compatibility and validation evidence, and merges accepted work.
Technical disagreement should be resolved with a concrete scenario or reproducible test.

Changes to the workflow contract, supported runtimes, license or publishing process should explain
their impact in the pull request and changelog. Releases follow [RELEASING.md](docs/RELEASING.md).

Additional maintainers can be proposed in an issue. Repository permissions change only after the
current maintainer accepts the proposal and agrees responsibilities with the person involved.

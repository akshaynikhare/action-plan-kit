# Support

Start with [installation and upgrades](docs/INSTALLATION.md), [the workflow guide](docs/USAGE.md),
and [troubleshooting](docs/TROUBLESHOOTING.md).

- Questions and usage discussions: [GitHub Discussions](https://github.com/akshaynikhare/action-plan-kit/discussions).
- Reproducible bugs and feature requests: [GitHub Issues](https://github.com/akshaynikhare/action-plan-kit/issues/new/choose).
- Suspected vulnerabilities: follow [SECURITY.md](SECURITY.md).
- Conduct concerns: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

For a useful bug report, include the kit version, operating system, Node.js version, command,
expected result, actual result and a minimal example. Redact credentials, private code and customer
data from logs. This is a community-maintained project; response times are not guaranteed.

To support maintenance, see [sponsorship and other ways to help](SPONSORING.md).
